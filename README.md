## 🚀 Tech Stack

### 🖥️ Frontend

- React.js  
- React Router DOM  
- Context API  
- Tailwind CSS  
- Axios  
- React Hook Form  
- Framer Motion  

### ⚙️ Backend

- Node.js  
- Express.js  
- PostgreSQL (Neon)  
- Prisma ORM  
- JWT Authentication  
- BCrypt  
- Role-Based Access Control  

### ☁️ Deployment

- Frontend → Vercel  
- Backend → Render  
- Database → Neon PostgreSQL

## ✨ Features

### 👤 User

- 🔐 Authentication (Signup/Login)  
- 🛍️ Browse Products  
- 🛒 Cart Management  
- 📦 Order Placement  
- 🔍 Search & Filtering  
- 🎨 Smooth UI Animations  

### 👑 Admin

- ➕ Add Products  
- ✏️ Update/Delete Products  
- 📦 Manage Orders  
- 👥 Manage Users  

### ⚡ Backend

- JWT Authentication  
- RBAC Authorization  
- Token Bucket Rate Limiting  
- Input Validation  
- Global Error Handling

## 🧠 Architecture

Frontend (React)

↓

API Layer (Axios)

↓

Backend (Node + Express)

↓

Prisma ORM

↓

PostgreSQL Database
